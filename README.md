# うえだ歯科医院 インプラント情報サイト

鹿児島市の「うえだ歯科医院」による、インプラント治療を検討する方向けの情報サイトです。インプラントを一方的に勧めず、入れ歯・ブリッジを含む選択肢を比較し、費用・期間・リスクを理解して相談できる体験を目指しています。

## 開発

```bash
npm install
npm run dev
```

品質確認：

```bash
npm run typecheck
npm run build
```

## 環境変数

`.env.example` を参照してください。本番URLとサブディレクトリ公開用のベースパスをコードにハードコードせず管理します。`NEXT_PUBLIC_PRODUCTION=true` にするまでは `robots.txt` が全体を noindex にします。

## 公開前に必要な確認

- 上田院長による医療内容・経歴・資格・所属の最終確認
- 現在の正式料金、治療期間・通院回数の確認
- 診療時間、予約URL、駐車場情報の確認
- 医療広告ガイドラインに基づく表現確認
- GA4、Search Console、公開ドメインの設定

取得した公式サイト掲載写真はユーザーから新サイトでの使用許可を得ています。出典と管理状況は `docs/asset-permissions.md` に記録しています。
