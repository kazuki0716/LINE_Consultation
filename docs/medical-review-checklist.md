# 医学監修・公開前チェックリスト

## 要確認

- トップページの診療方針コピー
- インプラント・ブリッジ・入れ歯の比較表
- 治療工程と工程ごとの説明
- FAQの全回答
- 標準的な費用、費用に含まれる項目、追加費用
- 標準的な治療期間と通院回数
- 主なリスク・副作用、治療が適さない可能性があるケース
- 院長の経歴、資格、所属の正式名称と現在の状況
- 診療時間、駐車場、正式な予約方法・URL

## 公開制御

- 記事は `review_required` として管理し、`robots` で検索対象外
- 本番確認までは `NEXT_PUBLIC_PRODUCTION=false` とし、サイト全体を noindex
- 確定していない料金を具体的な本番料金として表示しない
